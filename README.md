# Minutes Server
A website for hosting meeting minutes, geared toward corporations in a Democratic/Sudbury school

## State of the project
This website is very much in Alpha and is not considered secure at all. I would not recommend storing anything confidential, exposing the site to the internet, or using this as your only method of storing data. This website was created to be a more accessible and centralized alternative to secretaries storing minutes in their personal cloud storage, and not as the primary method of storing meeting minutes.
